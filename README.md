## 🎯 Purpose

The main goal of these projects is to practice Machine Learning through implementation rather than only studying algorithms theoretically.

For each project, I focused on applying the selected algorithm to a dataset and gaining practical experience with steps such as:

- Data exploration and preprocessing
- Feature preparation
- Model training
- Model evaluation
- Visualization
- Comparing model performance
- Understanding the practical behavior of different algorithms

The projects are intentionally small and focused, making it easier to study each algorithm individually and understand how it works in practice.
